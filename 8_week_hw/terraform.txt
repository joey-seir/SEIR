Explain the mandatory (required) arguments for a VM in terraform 
Name - the unique identifier for your VM instance within the project and zone 
Machine type - determines the hardware specs (CPU and RAM) for your instance 
Boot disk - defines the VM’s operating system disk. It must include at least at source or initialize_params
Network interface - GCP VM must be attached to at least one network interface
